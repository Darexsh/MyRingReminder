## 2. Ambito di applicazione
La presente informativa si applica all’app Android MyRingReminder (`com.darexsh.myringreminder`), distribuita tramite questo repository e tramite versioni APK.

## 3. Dati trattati da MyRingReminder
MyRingReminder tratta i dati dell’app necessari per il monitoraggio del ciclo e la personalizzazione, tra cui:
- date e cronologia dei cicli
- registrazioni del ciclo mestruale (per esempio l’indicazione di un giorno di mestruazione, l’intensità del sanguinamento, sintomi come dolore o malattia e marcatori facoltativi di inizio e fine)
- impostazioni dei promemoria e orari delle notifiche
- note inserite dall’utente
- preferenze di design (colori, sfondo e lingua)
- impostazioni facoltative del blocco dell’app

## 4. Archiviazione locale dei dati
MyRingReminder conserva i tuoi dati localmente sul dispositivo (per esempio tramite SharedPreferences o l’archiviazione locale dell’app).

MyRingReminder non carica sullo sviluppatore i tuoi dati personali sul ciclo o le tue note.

Se utilizzi il backup o il ripristino, i dati vengono esportati o importati come file locale selezionato da te tramite il selettore file di Android.

Se esporti in PDF i dettagli del ciclo, il PDF viene generato localmente sul dispositivo e salvato solo nella posizione che scegli tramite il selettore file di Android.  
Quando apri il PDF dalla notifica dell’app, Android può passare il file a un’app di visualizzazione PDF scelta da te. In tal caso, tale app tratta il file secondo la propria informativa sulla privacy.

## 5. Autorizzazioni utilizzate
MyRingReminder può richiedere le autorizzazioni necessarie per le funzioni dell’app, per esempio:
- notifiche e allarmi esatti (promemoria del ciclo)
- accesso a file o contenuti multimediali (selezione dell’immagine di sfondo, backup e ripristino)
- dati biometrici o credenziali del dispositivo (blocco facoltativo dell’app)

Le autorizzazioni vengono utilizzate esclusivamente per fornire le funzioni dell’app richieste.

## 6. Analisi, tracciamento e segnalazione degli arresti anomali
In base all’implementazione attuale, MyRingReminder **non** include SDK di terze parti per analisi o segnalazione degli arresti anomali.

## 7. Rete e link esterni
Le funzioni principali di MyRingReminder sono locali e non richiedono un’API backend dedicata per il monitoraggio del ciclo.

Per verificare la disponibilità di aggiornamenti, MyRingReminder può richiedere i metadati delle release tramite l’API pubblica GitHub Releases di questo progetto.

Quando apri **Impostazioni → Foglietto illustrativo**, l’app richiede il file pubblico `leaflet-packages.json` dal repository GitHub di questo progetto. Quando apri **Informazioni app → Informativa sulla privacy**, richiede il file dell’informativa corrispondente alla lingua selezionata nell’app; se una traduzione non è disponibile, viene usata la versione inglese. Queste richieste non includono i tuoi dati del ciclo, le note o le impostazioni dell’app. GitHub può trattare informazioni ordinarie di connessione, come il tuo indirizzo IP e le intestazioni della richiesta, secondo la propria informativa sulla privacy. L’app conserva sul dispositivo l’ultima copia scaricata correttamente per ogni lingua, così potrai leggerla anche se una richiesta successiva non va a buon fine.

Su tua richiesta, MyRingReminder può aprire destinazioni esterne tramite intent di sistema, tra cui:
- e-mail (`mailto:`)
- Linktree
- Telegram
- GitHub
- Buy Me a Coffee
- foglietti illustrativi ospitati da servizi esterni di informazione sui medicinali o dai produttori

Quando apri un foglietto illustrativo, Android passa il relativo URL al browser o al visualizzatore di documenti scelto da te. Il servizio che ospita il documento riceve la richiesta; l’URL può rivelare il prodotto e la lingua del foglietto. Il browser, il visualizzatore e il servizio che ospita il foglietto possono trattare informazioni ordinarie di connessione secondo le proprie informative sulla privacy. MyRingReminder non allega a queste richieste i dati del ciclo, le note o le impostazioni conservati localmente.

Quando apri link esterni, si applicano le informative sulla privacy dei relativi servizi di terze parti.

### Servizi di terze parti menzionati nei link
- GitHub: https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement
- Telegram: https://telegram.org/privacy
- Linktree: https://linktr.ee/s/privacy
- Buy Me a Coffee: https://www.buymeacoffee.com/privacy-policy

## 8. Condivisione dei dati
In base all’implementazione attuale dell’app, MyRingReminder non trasmette allo sviluppatore i dati del ciclo, le note o le impostazioni conservati localmente.

## 9. Avvertenza medica
MyRingReminder è esclusivamente uno strumento di organizzazione e monitoraggio.

Non è un dispositivo medico, non fornisce diagnosi mediche e non sostituisce il parere di un professionista sanitario.

Per domande mediche o problemi di salute, rivolgiti a un professionista sanitario qualificato.

## 10. Le tue opzioni
- Puoi modificare o eliminare i tuoi dati all’interno dell’app.
- Puoi revocare le autorizzazioni dell’app nelle impostazioni di Android.
- Puoi scegliere di non aprire link esterni.
- Puoi disinstallare l’app e cancellare i dati locali dalle impostazioni di Android.
