## 2. Область действия
Эта политика распространяется на приложение MyRingReminder для Android (`com.darexsh.myringreminder`), которое распространяется через этот репозиторий и в виде APK-релизов.

## 3. Какие данные обрабатывает MyRingReminder
MyRingReminder обрабатывает данные приложения, необходимые для отслеживания цикла и персонализации, включая:
- даты цикла и историю циклов
- записи о менструации (например, отметку дня менструации, интенсивность кровотечения, симптомы, такие как боль или заболевание, а также необязательные отметки начала и окончания)
- настройки напоминаний и время уведомлений
- заметки, введённые пользователем
- настройки оформления (цвета, фон и язык)
- необязательные настройки блокировки приложения

## 4. Локальное хранение данных
MyRingReminder хранит ваши данные локально на устройстве (например, в SharedPreferences или локальном хранилище приложения).

MyRingReminder не передаёт разработчику ваши личные данные о цикле или заметки.

При использовании резервного копирования или восстановления данные экспортируются или импортируются как локальный файл, выбранный вами в системном файловом интерфейсе Android.

При экспорте сведений о менструации в PDF файл создаётся локально на устройстве и сохраняется только в месте, выбранном вами в системном файловом интерфейсе Android.  
Если открыть этот PDF из уведомления приложения, Android может передать файл выбранному вами приложению для просмотра PDF. В таком случае это приложение обрабатывает файл в соответствии со своей политикой конфиденциальности.

## 5. Используемые разрешения
MyRingReminder может запрашивать разрешения, необходимые для функций приложения, например:
- уведомления и точные будильники (напоминания о цикле)
- доступ к мультимедиа или файлам (выбор фонового изображения, резервное копирование и восстановление)
- биометрические данные или учётные данные устройства (необязательная блокировка приложения)

Разрешения используются только для предоставления запрошенных функций приложения.

## 6. Аналитика, отслеживание и отчёты о сбоях
Согласно текущей реализации, MyRingReminder **не** содержит сторонних SDK для аналитики или сбора отчётов о сбоях.

## 7. Сеть и внешние ссылки
Основные функции MyRingReminder работают локально; для отслеживания цикла отдельный серверный API не требуется.

Для проверки обновлений MyRingReminder может запрашивать сведения о выпусках через общедоступный API GitHub Releases этого проекта.

При открытии раздела **Настройки → Инструкция к препарату** приложение запрашивает общедоступный файл `leaflet-packages.json` из репозитория GitHub этого проекта. При открытии раздела **Информация о приложении → Политика конфиденциальности** оно запрашивает файл политики на выбранном языке приложения; если перевод недоступен, используется английская версия. Эти запросы не содержат ваши данные о цикле, заметки или настройки приложения. GitHub может обрабатывать обычные сведения о соединении, например IP-адрес и заголовки запроса, в соответствии со своей политикой конфиденциальности. Приложение хранит на устройстве последнюю успешно загруженную копию для каждого языка, чтобы её можно было прочитать, если следующий запрос завершится ошибкой.

По вашему запросу MyRingReminder может открывать внешние ресурсы через системные intent, в том числе:
- электронную почту (`mailto:`)
- Linktree
- Telegram
- GitHub
- Buy Me a Coffee
- инструкции к препаратам, размещённые внешними информационными службами или производителями

При открытии инструкции Android передаёт её URL выбранному вами браузеру или приложению для просмотра документов. Сервис, на котором размещён документ, получает запрос; URL может раскрывать название продукта и язык инструкции. Браузер, приложение для просмотра и хостинг инструкции могут обрабатывать обычные сведения о соединении согласно своим политикам конфиденциальности. MyRingReminder не добавляет к этим запросам локально сохранённые данные о цикле, заметки или настройки.

При открытии внешних ссылок применяются политики конфиденциальности соответствующих сторонних сервисов.

### Сторонние сервисы, указанные в ссылках
- GitHub: https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement
- Telegram: https://telegram.org/privacy
- Linktree: https://linktr.ee/s/privacy
- Buy Me a Coffee: https://www.buymeacoffee.com/privacy-policy
